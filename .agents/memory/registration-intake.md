---
name: GO COURSE public registration
description: Requirements for the visitor registration and manual payment-proof flow.
---

Visitors should be able to start a registration request from the homepage, and submitted requests belong in the administrator section named «طلبات التسجيل». For an approved price, payment proof is uploaded privately and remains unverified until an administrator checks it. If a price is missing or under review, allow the request without payment proof and do not ask the visitor to pay before the price is approved.

**Why:** The user asked for homepage registration, an administrator request queue, and payment by receipt upload; the approved-pricing rules also prohibit charging for an unconfirmed price.

**How to apply:** Keep receipt files private and link them only to registration requests. Preserve the distinction between awaiting payment and awaiting proof verification; never treat upload as payment confirmation.
